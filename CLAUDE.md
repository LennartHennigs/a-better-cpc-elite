# CPC Elite

Goal: disassemble and improve an old Amstrad CPC game (Elite) from `disks/Elite_UK_original_protected.dsk`: commented, reassemblable source (`src/`) plus a modified build that runs on a CPC emulator. Docs are in `docs/` (start with `_build.md`, `_my_changes.md`, `_memory_map.md`, `_open_questions.md`; there is no `docs/notes.md`).

## Quick start

```bash
make test                 # rebuild disks, then check_src (en, de, fr), test_saves, test_disks (~45 s)
make test-quick           # the host tests on the disks already in build/ (seconds)
make test-emu             # cpcxray tests with pass/fail (~4 min: run it in the background, wait for the completion notice)
bash tools/check_src.sh [de|fr]   # assemble src/elite* and compare with the original bytes (the byte-exact proof)
make original [LOC=de|fr] # stock bytes on a bootable disk -> build/elite_original*.dsk (make stock = raw .bin only -> build/stock/)
make expanded             # everything on one disk -> build/elite_expanded.dsk (~50 s, English only); make missions, make enhanced likewise
python3 -I tools/dskx.py disks/Elite_UK_original_protected.dsk work/bin_stock   # list and extract (AMSDOS headers kept in .raw)
python3 -I tools/bastok.py FILE [--header]                                       # detokenize BASIC
```

`tools/README.md` indexes the tools, `tools/tests/README.md` the cpcxray tests: add a row when you add a script or test. Run Python tools with `python3 -I`.

## Rules

- **Never modify the original disks in `disks/`** (`.dsk` and `.cdt`, gitignored, third party). Work on copies. A tool that writes a disk image must call `dskx.is_original(path)` and refuse (project root and anything under `disks/`).
- Folders: `build/` (gitignored) is where `make` targets leave their result; `make clean` removes it; a make target writes only there, and scripts do not copy results into `work/xray/disk/` (copy by hand for a cpcxray test; `run_all.py --emu` does it). `work/` keeps intermediates, extracted files and single-tool output, `src/` annotated assembly, `traces/` traces. Third-party disk images go in `work/` (e.g. `work/plus_patch/`), never `tools/` or the root. `build/README.md` is copied from `tools/build_readme.md`: edit the template.
- Never edit or delete files named `* 2.*` (Finder duplicates, untracked); tell the user. Deleting many untracked files is blocked by the auto-mode classifier: list them, get the user's explicit go-ahead.
- Target is Z80 on a CPC 464/6128 (64 KB stock; Elite is tight). Write assembly in sjasmplus syntax. Keep AMSDOS headers intact when writing binaries to disk (load, exec, length, checksum).
- On every disk we build, `CAT` shows only `.BAS` and `.TXT` files (and commander saves); every other file gets the System attribute. `tools/build_dsk.py` does it for all variants, `tools/hide_files.py DISK` for finished images; iDSK adds files unhidden, so hide again after any `iDSK -i`/`-r`. Check with `CAT` or the directory, not `iDSK -l` (it lists hidden files). Saves stay visible on purpose (the game's load menu and `LISTSAVE` use `CAT`).
- **Save key:** the 104 bytes at `EquipShip` (`LARGEAXX` file offset `&2BE` stock, `&2C2` German) decode every commander save. Plans must leave them as they are; if a plan would change or move them (a tweak in that code, a shifted table before it, a build flag), tell the user first. `check_src.sh` and `test_disks.py` check it.
- Fessor's material stays out of the repo (see `extended/CLAUDE.md`). Exception (his private mail, the user's go-ahead 2026-11-14): the Constrictor hull (`missions_hull.asm`), the hulls in `missions_ships.asm` (`tools/fessor_ships.py`, `docs/_ship_packs.md`) and his names and findings in the source, credited in `README.md` and `NOTICE`. The `double-buffer` branch patches his source: it stays local, never push it.
- `README.md` must not name or describe any mission (counts and sources only; the missions are secret; tables use sizes and numbers); the one exception is the credit to Fessor for the Constrictor hull. Licences: `LICENSE`, and list new third-party-derived files in `NOTICE`. `src/disk/README.TXT` (written onto the mission disk): add a very short line per player-visible feature or tool, CRLF, about 32 characters per line.
- Building downloaded source in Bash is blocked by the permission classifier: put it in a script under `scripts/` and ask the user to run it (`! bash scripts/…`); do not work around the block. `scripts/` has only `install-tools.sh` (sjasmplus, iDSK).
- Commit code and docs separately, with explicit paths (`git add FILE...`); the user edits files while you work, so run `git status` and `git diff --stat` first and tell them what is not yours (docs often carry their pending edits). If every file shows `D ` plus `??`, the index was emptied: `git reset -q`.
- Docs: edit the `docs/` file when you change a fact; moving a doc to `docs_other/` (untracked) leaves dead links, so grep `CLAUDE.md`, `README.md`, `docs/`, `TODO.md`, `src/` for the name and mark it "(local only)". `TODO.md`: open items on top, finished ones in `## Done` (move, don't delete). `CHANGELOG.md`: newest first, a title plus one or two sentences. `magazines/`: only its README is tracked.

## Disks and game facts (details and hashes in `docs/_disks.md`)

- `Elite_UK_original_protected.dsk`: UK original ("Version GOLD"), 41-track extended DSK, every file System-hidden, decoy directory entries, ARMOURLOC v1.1. `CAT` shows only `0K free`; use `iDSK x.dsk -l` or `dskx.py`. `LOAD"ELITE.BAS` is wiped by BASIC on return to the prompt (flag `&AE2C`): stop at `&C06A` and write `0` there; `RUN` is fine.
- `Elite_UK_Firebird_cracked_trainer.dsk`: same English game, unprotected, plus Firebird's `CHEAT.BAS` (wrong cloak entry). **Start here.** Our trainer is `TRAINER.BAS` (`RUN"TRAINER`; on the mission and expanded disks it replaces `CHEAT.BAS`; cloak key `Y`; `docs/_cheats.md`).
- `Elite_DE_cracked.dsk` German build (already has the CPC+ fix); `Elite_DE_savegames.dsk` four saves (German key); two French disks (`Elite (1985)(Firebird Software)(fr).dsk`, `...[a].dsk`, `Elite__(Adaptation_Plus)...`) in `disks/`. Tracks 1 and 40 of the 41-track disks use odd sector IDs but hold only `0xE5`: not a loader. `Elite_DE_cracked.dsk` holds `COMMONXX` twice (tracks 7, 27) and its AMSDOS headers have load address 0 except `COMMONXX.BIN` (`&1A40`): set them when writing a DSK.
- Load sequence (`ELITE.BAS`): picture to `&C000`, `largeaxx` to `&840`, `commonxx` to `&1A40`, `common2x` to `&C000`, `CALL &1C82` (entry). `MUSIQUEX.BIN` loads at `&6000` over `COMMONXX`'s `&6000-&6FFF` while music plays (`NOTMUSIC.BIN` is that slice): never lay both into one image, use `COMMONXX` alone.
- The CPC port is a Spectrum port, not a BBC port: use the 6502 sources only for naming and logic. Poke addresses of `CHEAT.BAS` (`docs/_cheats.md`) anchor routine names. Poke and patch addresses are often operand bytes: disassemble from `addr-1` to `addr-4` and keep the start that decodes sensibly.
- Elite swaps `&0040-&1A3F` with `&A600-&BFFF` at runtime, so the BASIC program at `&170` is destroyed once the game runs (dump it early: write breakpoint on `&840`). Layout: `docs/_memory_map.md`. Do not put code in the parked block's zero runs (content depends on how the game was started; RVM crashed with markers there; `docs/_memory_map.md`).
- Self-modifying code (line plotters): confirm static results with traces. `halt` resumes on every interrupt (6 per frame, 300 per second): `djnz`+`halt` delays are B/300 s. A binary started with `RUN"X.BIN` has the cassette vectors selected (`CAS_IN_OPEN` asks "Press PLAY") and the lower ROM off (`KL L ROM ENABLE` `&B906` for the font); put everything it needs into its own file (`dskx.py add_payload`).
- Commander save: 104 bytes at `&38CB`, XORed with the code at `EquipShip`; a save decodes only with its own build's key (`tools/savedec.py SAVE DISK.dsk`, `elitekey.py`; fields in `docs/_savegame.md`). Credits are a word pair (high word counts 1,000 Cr, low word decicredits below 10,000), not 32 bits. To tell which build a blob is from, XOR-scan it against `work/bin_*/*.BIN`.
- CPC tokenised BASIC: constants `0x0E–0x18` are 0–10, `0x19` byte, `0x1A` int16, `0x1C` hex, `0x1F` 5-byte real, `0x01` `:`, `0xFF` prefixes functions. `src/cheats/*.ASC` need CRLF lines and a final Ctrl-Z or the tokeniser silently makes an empty 2-byte program (`wc -c src/cheats/*.BAS` after a rebuild). Renaming a program: the name is in the `.BAS` header (8 characters), so replace it in sources, scripts and docs and rebuild with its build script, never just `git mv`.
- Terms: "status" is `legalStatus`, "rating"/"rank" the kill-score rank from `getRank` (`docs/_gameplay.md`). `posDataPlanet` `&1C2F` and `posDataSun` `&1C26` are x, y, z as lo, hi, sign bytes (planet far left: `00 FF 80 00 00 00 B6 7C 01`; `&1A40+7` is not the planet). `aspMissionState` (Spectrum `$9CB2`, 0-3) and `spawnEscortPack` (`$BCAB`) are named.

## Toolchain (macOS, Apple Silicon)

| Purpose | Tool |
|---|---|
| Analysis emulator | **cpcxray** 0.9.4 (traces, disassembly, MCP server), `~/.local/bin/cpcxray` (not on PATH), project folder `work/xray/`; headless and GUI both work |
| Other emulators | RVM 2.1 (play and compare; debugger has only PC `break`, `poke`, `load`/`save`); MAME and konCePCja (TCP protocol on `localhost:6543`, watchpoints) are not installed or built: a new use needs a build script under `scripts/` that the user runs |
| DSK / tape | iDSK `~/.local/bin/iDSK` (`-l` lists hidden files); CDTconvert (installed by hand) and `tools/cdt_direct_decode.py` for the English tape |
| Assembler | sjasmplus 1.24.0 (`~/.local/bin`, built by `scripts/install-tools.sh`, not in Homebrew); RASM 3.3.2 at `tools/bin/rasm` only for Fessor's source (rebuild: `cc -O2 -DNO_3RD_PARTIES -DNOAPI -o rasm rasm.c -lm -lpthread`; the repo's makefile fails to link) |
| Disassembly | cpcxray first, z80dismblr, Ghidra (not installed) |

Shell: zsh does not word-split unquoted variables (`${=VAR}`) and `echo =====` fails (use `printf -- '---\n'`); an unmatched glob aborts the command. macOS BSD `sed` has no `\b` (use `perl -pi -e 's/\bold\b/new/g'` and confirm with a grep count) and `sed -i ''` needs the empty suffix; for multi-line edits use a `python3 -I` script with exact-match asserts. BSD `cat` has no `-A` (`cat -et`). `rtk` truncates long Bash output (use Read or a `python3 -I` script), rewrites `grep`/`ls`/`diff`/`cat` and may refuse the first attempt ("a hook changed this call's input"): reissue unchanged; `rtk diff` is useless for file-vs-file, use `difflib`. A `cd` in a Bash call persists: use `(cd dir && cmd)` or absolute paths. Foreground Bash stops at 2 minutes: start long runs detached (`python3 -c "subprocess.Popen([...], start_new_session=True, stdout=open(f,'w'), stdin=subprocess.DEVNULL)"`, no `setsid`/`nohup &` on macOS) and poll the output file; save a snapshot at the interesting state instead of rerunning the boot. Web pages behind Cloudflare (GameFAQs, CPCWiki) return 403 to `curl`/WebFetch: use Claude in Chrome (`navigate`, `javascript_tool` `document.querySelector('#faqwrap').innerText` or `get_page_text`) and save third-party text under `docs/` with its source URL.

## cpcxray and tests

- GUI: `export PATH="$HOME/.local/bin:$PATH"; cd work/xray && cpcxray gui --config config/cpc6128.toml` (MCP on `127.0.0.1:8765`); mount disks read-only (the `disk_insert` default). The GUI flickers: play and test visually in Virtual Retro, use cpcxray for tracing.
- Scripting: cpcxray's own Python (`~/.local/share/uv/tools/cpcxray/bin/python -I script.py`), `mcp.client.stdio.stdio_client(StdioServerParameters(command="cpcxray", args=["mcp"]))`, run from `work/xray/` (relative `config/`, `disk/`, `output/`). Attaching to the GUI: `streamable_http_client("http://127.0.0.1:8765/mcp")` (two streams). Tools: `disk_insert`, `type_text`, `run_until`, `sna_load`/`sna_save`, `memory_save`, `disassemble`, `screen_image` (its Python has no PIL: crop with the system `python3`).
- API gotchas: `memory_view`/`memory_read` show ROM under the lower ROM and `view="ram"` returns zeros: use `ram:0` (or `ram:N`) or `view="cpu"` after paging. `memory_write(address, data="3E 05")`, `registers_set(values={"pc": 0x9000})`, `breakpoint_add(address, end=, kind="pc"|"write")` (a range), `breakpoint_remove(breakpoint_id)`. `run` reports `time_limit`, not a breakpoint stop: count hits with `breakpoint_list`. `bus_trace_read` returns 100 records unless `last=` (max 2000), `trace_read` at most 1000 lines; time with `machine_status["clock_us"]`; a non-deterministic interrupt phase makes single runs differ: compare with interrupts off (`registers_set iff1=0`). Boot-time work: `type_text(text, wait=False)` then `run(max_us=...)`; after boot wait about 4 s before `type_text`; in `type_text` the quote in `RUN"ELITE` can come out garbled (check the first screenshot).
- Test routines in flight from `output/firebird_in_flight.sna` (the game just launched), not `firebird_at_entry.sna` (docked layout: the ISR at `&0038` still jumps into the bitmap; half-initialised, it corrupts menu/disk tests, which need a clean boot). `disk_insert(drive="A", path=...)` BEFORE `sna_load` (else "Drive A: disc missing"). Stop at `handleEntitys` `&5066`, push a trap address, call, compare; to keep playing afterwards save `registers_get` (af, bc, de, hl, ix, iy, sp, pc) first and `registers_set` them back (`tools/tests/test_trumbles_screens.py`). Whole-RAM compare: `sna_save`, read 64 KB at offset `0x100` of the .sna (flat layout; 128K: bank n at `0x100 + n*0x4000`; `memory_read` shows only the current map and `view="ram:N"` returned the same bytes for every N). Disc loads take several emulated seconds: run 10-15 s before reading results.
- Driving the game: hold keys 1.2-1.5 s (`key_press`, `run`, `key_release`; shorter holds are missed); key names `cursor_left`, `space`, `f1`. Title `y` opens the disk menu (`1` load, `2` save, `4` exit; `FileMenu` is only called from the title loop, so scripts cannot reach a save in play); in flight `5` galactic chart, `6` short range chart, `7` data on present system, `9` status page (press `8` between values), `h` hyperspace to the system nearest the cursor (needs fuel, cursor within ~7 LY; a 0.2 s `cursor_left` tap from Lave reaches Diso), `cursor_*` move it (`PresentPlanetX/Y` `&3934/&3935`, ~22 steps per second). Kills: word at `&38D8` (`killScore` `&38D7`), written with `memory_write`. Key to flag mapping: `tblKeyboardMatrix2` (`&8D37`, line*8+bit; code>>3 is the `&8D87` byte, code&7 == 0 is bit 7).
- Do not edit `src/` while `make expanded` or a test runs (tests assemble from `src/` at start). `sjasmplus --sym/--raw/--lst` writes where you run it: for measurements copy `src/elite` into the scratchpad; it is on PATH only inside `check_src.sh` (otherwise `export PATH="$HOME/.local/bin:$PATH"`); grep `": error:"`, not `"error"`. `check_src.sh` success lines say "differs only in ...": judge by exit code or grep `FAILED|DIFFERS|differs outside|CHANGED`; it also passes on an unchanged tree, so it does not catch a rename that matched nothing. `tools/add_files.py DISK -NAME.EXT` deletes a file from an image, `NAME.EXT=FILE` adds one. Add files to Firebird-based disks with `dskx` (as `build_dsk.py`), not iDSK, which may fill the two odd-sector tracks AMSDOS cannot read (`Drive A: read fail`); viewer data must stay below `&A67B` while loading.

## Editing the source

- Disassembly of the stock English build is done and byte-exact. Once you hand-edit the `.asm` files, **never rerun `tools/disasm_stock.py` (or `disasm_german.py`/`disasm_french.py`) into `src/*`**; give it a scratch dir (`python3 -I tools/disasm_stock.py /tmp/x`). After every change assemble and compare (`check_src.sh`) before changing behaviour; back up `src/elite/` before bulk edits. `tools/relabel.py TARGET REFERENCE --write` folds `db` runs into instructions using a fresh reference; `src/elite_de`/`src/elite_fr` still have them. `tools/z80dis.py` decodes `push/pop ix/iy`, `ex (sp),ix`.
- Renaming a label in `src/elite/`: apply it to `src/elite_de/` and `src/elite_fr/` too (one label: `perl` on all trees + `check_src.sh` for en, de, fr; many: regenerate into a scratch dir and diff with difflib, copy `commonxx.asm` over only if just renames/comments differ). `tools/rename_dat.py` only handles `dat_` labels (map in `tools/rename_maps/`). To find every use of a variable grep all of `src/elite/*.asm` for both the label and the number (`0x38E1`): `largeaxx.asm` and `common2x.asm` use raw addresses. Cite routines in docs by label unless you checked the address in a listing or trace; guessed `&xxxx` values are not stable. Source comments cite doc sections: after renumbering docs, grep `src/`, `TODO.md`, `docs/`.
- Names and the Spectrum map: `python3 -I tools/spectrum_map.py && ... spectrum_data_map.py && ... gen_spectrum_map_doc.py` regenerates `work/spectrum_map/` and `docs_other/_spectrum_map.md`. His source builds the patched game only; the `.rar` files are RAR5 (`bsdtar`, not `7z`); RASM `SAVE ...,AMSDOS` has a 128-byte header to strip (`[128:]`) before comparing.

## The mods (`-DENHANCED`, `-DMISSIONS`, `-DTRAFFIC`, `-DTITLESEL`)

- The default build keeps the original bytes (apart from the CPC+ fix in en and fr); changes sit behind flags and `check_src.sh` proves it: `-DENHANCED` may differ only in the documented slots. `-DENHANCED` needs `STAR_OCCLUDE` (an `ASSERT`); the disks use `-DENHANCED -DTITLESEL -DTRAFFIC -DMISSIONS`. `tools/build_dsk.py` builds English, `--missions`, `--de`, `--fr` (French boots with `RUN"EL`); it and the disk/disassembly scripts refuse the project root and `src/` as output (they need an OUTDIR).
- New `-DENHANCED` byte change: label the operand (`name equ $ - 1`), add `X=$(off name)` plus `o==x` to the awk in `check_src.sh` (COMMONXX; a tree without the label gets -99999), do all three trees. In `LARGEAXX` the awk uses `esym` (e.g. `escQtyOperand`, `-v qe=...` plus `o==qe`); retargeting a `jr` to another label keeps the size, so the save key does not move. Slots so far: `podCleanOperand`, `predelayOperand`, `hyperCountPos`, `cashHome`, `killHookSite`, `laserSightsJp`, `laserSightsBlock` (laser sights, on unless `-DMISSIONS` in English), `escQtyOperand`. Star occlusion: `dustPlotPixel` lives in the dead `unusedViewBorderFill` (`&1FD2-&1FF0`); ship hulls stay see-through (`docs/_ship_occlusion.md`, not built).
- Free flight-time space is only the 610 zero bytes at `&9D9E-&9FFF` (top bytes carry stack pushes at `&A000`) plus 3 in `unusedViewBorderFill`; `unusedGet*` (10 bytes) holds `killSpace`. With `-DMISSIONS` the tail is full (largest image 608 of 608), which is why the laser sights are off there. Measure images with `-DENHANCED -DTITLESEL -DTRAFFIC -DMISSIONS -DFL_x` (the disk's flags: plain `-DMISSIONS` gives different layouts, `test_launch.py` needs the same flags), size = `mxFlightEnd - mxFlightBase` from the sym file. Overview, sizes, order, tests: `docs/_missions_built.md`, `docs/_ship_packs.md`; research `docs/_missions.md`. Added missions: the stub and overlays sit in the `LARGEAXX` tail, the vector table and one flight image in the `COMMONXX` tail. Picker: `(jumpCounter + presentSystemSeed) & 7` in `mxLaunchEntry`, 0 = default image.
- The 128K version is on branch `elite128` (worktree `work/wt_elite128`). The double-buffer experiment (branch `double-buffer`, local only; write-up `docs_other/_double_buffer_experiment.md`): the user runs `bash scripts/build-fessor-dbuf.sh [adresschange|mylinedraw|banks]` (a patched copy in `work/dbuf`), then `bash tools/dbuf_disk.sh`, then the cpcxray python runs `tools/test_dbuf.py` or `tools/test_dbuf_flight.py` (paths on that branch); check `work/dbuf/EliteMasterSource.asm` for the flags and patch markers to see whether the user's build really ran.
- A save on a write-protected disk resets to BASIC (not confirmed whether the stock game does the same). Star occlusion screens: `tools/tests/test_star_occlusion.py [off] [far] [sun]` (PNGs in `output/stars_*.png`). Timing one routine: `tools/tests/test_keydelay.py`.
