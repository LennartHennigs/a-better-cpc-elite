# magazines/

Period magazine scans about the CPC version of Elite. Reference only; copyrighted, not for redistribution.

| File | What | Text | Pages used |
|---|---|---|---|
| `Amstrad_Action_003.pdf` | Amstrad Action no. 3, December 1985 (archive.org `amstrad-action-003`). Pre-release preview of Elite on the CPC. | `text/Amstrad_Action_003.txt` | 70-71 |
| `Amtix_Magazine_Issue_13.pdf` | Amtix, November 1986 (archive.org `Amtix_Magazine_Issue_13`). Interview with Ricardo Pinto of Torus, the CPC programmer. | `text/Amtix_Magazine_Issue_13.txt` | 84-86 |
| `elite-commander.pdf` | Schneider CPC International Sonderheft 3/86, pp. 67-68: type-in BASIC *ELITE: Commander nach Wunsch* (Thomas Kochmann), a commander creator. | `text/elite-commander.txt` | 67-68 |

Each PDF holds only the relevant pages. The text files come from
`pdftotext -layout FILE.pdf text/FILE.txt`; the columns are interleaved and the Amstrad Action scan is garbled
by OCR, so check the PDF before quoting. The findings are summarised in `docs/`.
