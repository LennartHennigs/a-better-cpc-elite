# src/cheats/

CPC BASIC programs and the small Z80 routine behind one of them. They run on the CPC itself, from the mission disk (`make expanded`) or one of the `work/*_cheat.dsk` test disks; docs: `docs/_cheats.md`.

Each program has up to three files: `NAME.ASC` (the text source, CRLF lines ending with Ctrl-Z), `NAME.BAS` (the tokenised file with its AMSDOS header, made by the CPC's own BASIC through `tools/build_cheat.sh`, never edited by hand) and `NAME.BAS.txt` (a readable listing of that `.BAS`). Change the `.ASC` (or the generator named below) and rebuild.

| Program | Run with | What it does | Source |
|---|---|---|---|
| `TRAINER` | `RUN"TRAINER` | Interactive trainer, stage one: asks what you want (shields and fuel, missiles, laser heat, hold size, cloak, jumps, kills, cash and more), then chains to `CHEATB`. Runs on the UK, German and French builds and on the mission build. | `TRAINER.ASC`, hand-written |
| `CHEATB` | (chained by `TRAINER`) | Stage two: loads the game, detects the build and pokes the chosen values. Stored on the disks as the hidden `CHEATB.BIN`. | `CHEATB.ASC`, hand-written |
| `EDITSAVE` | `RUN"EDITSAVE` | Commander save editor on the CPC: detects the build from the save, edits the fields, recomputes both checksums. The host counterpart is `tools/saveedit.py`. | `EDITSAVE.ASC`, generated by `tools/mk_editsave.py` |
| `LISTSAVE` | `RUN"LISTSAVE` | Lists every commander save on the disk in drive A: file, build (UK, French or German), kills, cash. | `LISTSAVE.ASC`, generated by `tools/mk_listsave.py` |
| `SHOWSHPS` | `RUN"SHOWSHPS` | Ship viewer: all 30 models as a rotating wireframe with name, kills, bounty, speed and energy. Needs `SHIPS.BIN` (hidden). | `SHOWSHPS.ASC`, generated by `tools/mk_showship.py`; `showship.asm` is its Z80 frame routine (built into `SHIPS.BIN` by `tools/build_showship.sh`) |

`CHEAT_ORIGINAL.BAS.txt` is only a listing of Firebird's own `CHEAT.BAS` (from `Elite_UK_Firebird_cracked_trainer.dsk`), kept as the reference for the poke addresses. It is not built and not on any disk of ours.

Build: `bash tools/build_cheat.sh` (trainers and save tools, `work/*_cheat.dsk`), `bash tools/build_showship.sh` (viewer, `work/showship.dsk`), or `make expanded` for everything on one disk in `build/`. The `.ASC` files need CRLF line ends and a final Ctrl-Z, or the CPC tokeniser silently makes an empty program: check `wc -c *.BAS` after a rebuild. Original disks are never touched: the tools work on copies.
