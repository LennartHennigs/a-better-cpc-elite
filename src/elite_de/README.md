# Elite (Amstrad CPC), German build: reassemblable source

Generated by `python3 -I tools/disasm_german.py [OUTDIR]` from `work/bin_german/` (the files of `Elite_DE_cracked.dsk`, extracted with
`tools/dskx.py`), after `python3 -I tools/map_german.py` has paired the German code with the stock English code.
**Rerunning it with the default output directory overwrites these files, including any hand edits.** sjasmplus syntax.

| File | Original | Load address | Notes |
|---|---|---|---|
| `largeaxx.asm` | `LARGEAXX.BIN` | `&0840` | trading, planet text, save/load; German text tables follow the code |
| `commonxx.asm` | `COMMONXX.BIN` | `&1A40` | core; entry point `&1C82`; contains `NOTMUSIC.BIN` at `&6000-&6FFF` (checked: byte-identical) |
| `common2x.asm` | `COMMON2X.BIN` | `&C000` | print and draw routines in screen RAM; 270 bytes differ from English |
| `musiquex.asm` | `MUSIQUEX.BIN` | `&6000` | identical to the English file, copied from `src/elite` |

`INDICATO.BIN`, `PICTURE.BIN` and the BASIC loader `ELITE.BAS` are byte-identical to the English ones (the loader is the unprotected
English `ELITE.BAS` of the Firebird disk). The AMSDOS headers of the German disk carry a load address only for `COMMONXX.BIN` (`&1A40`);
the others have `0`. Keep that in mind before writing the files into a DSK.


## How the names were made

The German game is the English program with German text, so the two instruction streams are the same except for address
operands and a few German-only routines. `tools/map_german.py` walks both binaries in lockstep from the entry point (instructions must
have the same shape; 8-bit immediates are wildcards because German changes key codes and token numbers) and pairs every jump, call and
data operand. It paired about 81% of the English code bytes. Every English label with a pair gives the German address its name, and the
comment block above the English label is copied over, so the German source carries our English comments. What was not paired has
`sub_`/`loc_`/`dat_` names (about 140 labels against about 120 in `src/elite`). Names are only as good as the pairing: a wrong pair would be a
wrong name, but never a wrong byte, because every file is verified by assembling it.

## What differs from the English source

- Everything that is text: the token tables, planet descriptions, messages. Code addresses move by 10 to 0x148 bytes between regions.
  `EquipShip` is at `&0B02` (English `&0AFE`), so the German save key sits at `LARGEAXX` offset `&2C2` as `docs/_savegame.md` says.
- The system data screen has extra text calls (German word order), around `&43FD-&4495` against English `&42F6-&4390`, and
  `COMMON2X` has different text routines at `&EE9D-&EF76` and `&FE34-&FFC8`.
- The German `getPPI_Input` already has the CPC+ keyboard fix (second `out (c),a` is `out (c),c`), see `docs/_cpcplus.md`.
- Trailing zero bytes: 282 against 610 in `COMMONXX` (the German game has 328 more bytes of content).
- Key code constants differ in places (for example the yes/no test at `&1CF1`).
