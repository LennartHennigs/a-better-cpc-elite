# Elite (Amstrad CPC), French build: reassemblable source

Generated by `python3 -I tools/disasm_french.py [OUTDIR]` from `work/bin_fr/` (the files of `Elite (1985)(Firebird Software)(fr).dsk`,
extracted with `tools/dskx.py`), after `python3 -I tools/map_french.py` has paired the French code with the stock English code
(same method as the German build, see `src/elite_de/README.md`).
**Rerunning it with the default output directory overwrites these files, including any hand edits.** sjasmplus syntax.

| File | Original | Load address | Notes |
|---|---|---|---|
| `largeaxx.asm` | `LARGEAXX.BIN` | `&0840` | 4608 bytes (English 4608+): code 39%, French text tables follow |
| `commonxx.asm` | `COMMONXX.BIN` | `&1A40` | core, entry `&1C82`; 34240 bytes; contains `NOTMUSIC.BIN` at `&6000-&6FFF` |
| `common2x.asm` | `COMMON2X.BIN` | `&C000` | 440 bytes differ from English |
| `musiquex.asm` | `MUSIQUEX.BIN` | `&6000` | identical to the English file, copied from `src/elite` |

`INDICATO.BIN`, `PICTURE.BIN` and `MUSIQUEX.BIN` are byte-identical to the English files.

```bash
bash tools/check_src.sh fr     # all four files byte-exact against work/bin_fr (COMMONXX: apart from the CPC+ fix byte at &8F3F)
```

## Findings (2026-11-07)

- The French game is the English program with French text, like the German one. Mapping paired about 81% of the English code bytes
  (26931 of 33349), 4 conflicts, 86 divergences. The key-code table `tblKeyboardMatrix2` differs from the English one.
- **The French disk has no CPC+ keyboard fix** (`getPPI_Input` had two `out (c),a`; the German disk has `out (c),c`; see `docs/_cpcplus.md`). Our source carries the fix: `src/elite_fr/commonxx.asm` differs from `work/bin_fr/COMMONXX.BIN` in exactly one byte, `&8F3F` (`ED 79` -> `ED 49`), and `check_src.sh fr` expects it.
- The first disk's loader is the plain `E.BAS` / `EL.BAS` / `SPEED.BAS` set (`SPEED.BAS` pokes a small machine-code stub at `&1000` and runs `elite`),
  with `.BAK` copies of every file and an extra `PICTURE1.SCR` splash. Headers carry load addresses for all binaries; exec addresses are 0.
- The `[a]` disk is a compacted re-release ("COMPACTE PAR CHANY FROM NUL PART SYSTEM"): `ELITE.` (BASIC plus stub, load `&0140`, exec `&1A60`),
  and `ELITE.1`-`ELITE.7` for LOADERXX, COMMONXX, COMMON2X, LARGEAXX, NOTMUSIC, INDICATO, MUSIQUEX. The payloads are the same as the first disk's;
  only the embedded file-name strings differ (`ELITE .1`..`ELITE .7` in `LOADERXX` `&38`, `COMMONXX` `&6F6F`/`&6F7C`, `COMMON2X` `&30`).
  `LARGEAXX`, `NOTMUSIC`, `INDICATO` and `MUSIQUEX` are byte-identical to the first disk.
